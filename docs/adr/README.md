# Architecture decision records

Short records of decisions that shape the code, with the alternatives that were rejected.

| # | Decision |
|---|----------|
| [0001](0001-postgis-for-spatial-logic.md) | Do spatial logic in PostGIS, measured on `geography` |
| [0002](0002-land-release-records.md) | Model land release as method-tagged records under tasks |
| [0003](0003-same-rules-everywhere.md) | One rule module for API, importer and triage |
| [0004](0004-auth-and-separation-of-duties.md) | JWT + role permissions with separation of duties |
| [0005](0005-offline-field-reports.md) | Offline field reports with client-generated ids |
| [0006](0006-privacy-public-aggregates.md) | Public aggregates, private records, no victim names |
